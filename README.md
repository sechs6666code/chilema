# 今晚吃什么

一个移动端优先的互动晚餐决策应用。通过基础偏好、命运口味、菜系和具体菜品四层决策，把“随便”变成一道真正能去吃的菜。

## 功能

- 沉浸式逐题问答与返回修改
- 基础问题、口味、菜系、具体菜品多层随机转盘
- 160 道结构化具体菜品与约束筛选
- 辣度、温度硬条件保护，零结果时仅放宽次要条件
- 收藏、历史记录、短期去重、分享与附近餐厅搜索
- 深色模式、LocalStorage 状态恢复、PWA 与离线基础页面
- iPhone 安全区域、Android 触控和减少动态效果适配

## 本地运行

```bash
npm install
npm run dev
```

## 测试与构建

```bash
npm test
npm run build
```

项目部署在 `/chilema/` 子路径，推送到 `main` 后由 GitHub Actions 自动部署 Pages。
